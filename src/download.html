Build Requirements

System Requirements

  • OS: Windows 10/11 (x64) or Linux (x64)
  • GPU: OpenGL 4.6 compatible graphics card
  • Disk Space: ~500MB, including dependencies

Required Tools

  • C++20 compiler - MSVC on Windows, GCC or Clang on Linux
  • Windows: Visual Studio 2022 or JetBrains Rider, latest Windows SDK
  • Premake5 (bundled, used to generate the build)

Dependencies (bundled as submodules)

  • GLFW - Windowing and input
  • GLAD - OpenGL 4.6 loader
  • GLM - Math library
  • Assimp - 3D model loading
  • SOIL2 - Image loading
  • nlohmann/json - Serialization
  • Dear ImGui - Editor UI
  • ImGuizmo - 3D transform gizmos
  • Jolt Physics - Simulation and collision
  • Lua - Scripting
  • miniaudio - Audio playback

Build Instructions

  1. Clone the repository with submodules 
    git clone --recursive https://github.com/Caleb-Kronstad/Bonfire Bonfire
cd Bonfire
    The --recursive flag downloads all dependencies (~200MB)
  2. Windows 
    cd Scripts
Windows-Setup.bat
Windows-Build.bat
Windows-Run.bat
    Windows-Setup.bat runs Premake and generates a Visual Studio 2022 solution in Build/. Build settings (config, MSBuild path) are configured in Windows-Config.bat.
  3. Linux 
    cd Scripts
./Linux-Setup.sh [gcc|clang] [debug|release|dist]
./Linux-Build.sh [debug|release|dist] [--clean] [--bear]
./Linux-Run.sh [debug|release|dist]
    Arguments can be given in any order. Linux-Build.sh builds incrementally by default; pass --clean to force a full rebuild of the selected config, and --bear to generate a compile_commands.json at the project root for CLion. See Scripts/INSTRUCTIONS.txt for the full set of options.
